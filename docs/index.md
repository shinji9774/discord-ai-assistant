# AI アシスタントの使い方

Discord のサーバーで使える AI アシスタント（bot）の使い方です。サーバーのチャンネルで `/` を入力し、一覧からコマンドを選んで実行します（DM では使えません）。

## コマンド

| コマンド | できること |
|---|---|
| [/translate](translate.md) | 文章やファイルを翻訳する |
| [/ask](ask.md) | AI に質問する（必要なら Web 検索） |
| [/image](image.md) | 文章から図を作る |
| [/summarize](summarize.md) | チャンネルの会話を要約する |
| [/summarize-voice](summarize-voice.md) | Craig の録音を文字起こしして要約する |
| [/record-start・/record-stop・/record-optout](recording.md) | bot が録音して要約する |

`/help` は、コマンドの一覧とこのページへのリンクを表示します。

## 結果の公開範囲

`/translate` と `/ask` の結果は全員に見えます。`/image` と `/summarize` は公開範囲を選べます。ほかのコマンドの返信は、実行した本人にだけ見えます。

## 知っておくこと

- 実行直後は「考え中」と表示され、しばらくすると結果に置き換わります。
- 結果が 2000 文字を超えると、全文を `result.txt`（/ask と要約は `result.md`）として添付します。
- 回答が上限で途中で止まると、末尾に「（上限に達したため、途中までの結果です）」と付きます。
- 「処理に失敗しました。」と表示されたら、少し待ってから再実行してください。
- AI の回答は誤りを含むことがあります。大事な内容は確認してください。
