# /ask — AI に質問する

AI に質問し、答えを受け取ります。結果は全員に見えます。

## 引数

- `question`（必須）: 質問の内容。最大 6000 文字

## 例

`/ask question:Discord のスレッドとは何ですか？`

## 結果

質問を引用し、同じ言語で簡潔に答えます。前の質問は覚えていないため、必要な前提は毎回含めてください。

必要なときは Web を検索し、出典（ページのタイトルとリンク）を付けます。

質問は、日本（東京）の Amazon Bedrock の文章生成モデルへ送ります。Web 検索をするときは、検索語を日本（東京）の検索サービスへ送ります。詳しくは[プライバシーポリシー](privacy.md)を見てください。
