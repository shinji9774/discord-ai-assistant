# プライバシーポリシー

この AI アシスタント（bot）が扱う情報と、その扱い方を説明します。この bot は、運営者が追加を認めた Discord サーバーでだけ使えます。

## 扱う情報

| 情報 | 扱うコマンド |
|---|---|
| コマンドに入力した文章と選択肢 | すべてのコマンド |
| 添付したファイルと画像 | /translate、/image |
| チャンネルの投稿の本文、日時、投稿者の表示名 | /summarize |
| Craig の録音リンク | /summarize-voice |
| ボイスチャンネルの音声と話者の表示名 | /summarize-voice、/record-start |
| Discord のユーザー ID、サーバー ID、チャンネル ID | すべてのコマンド（処理と返信のため） |

## 送信先

情報は、処理のために次の外部サービスへ送ります。

| 送信先 | 送る情報 | 地域 |
|---|---|---|
| Amazon Bedrock（文章生成モデル） | /ask の質問、/summarize と音声の要約に使う会話や文字起こし、/image の依頼文 | 日本（東京） |
| Amazon Bedrock AgentCore Web Search | /ask の検索語 | 日本（東京） |
| Amazon Translate、Amazon Comprehend | /translate の文章とファイル | 日本（東京） |
| Amazon Transcribe | 録音の音声 | 日本（東京） |
| Amazon Bedrock（Stability AI の画像生成モデル） | /image の依頼文と元画像 | 米国 |
| Craig | /summarize-voice の録音リンク（録音の取得と、削除用リンクのときは録音の削除のため） | 各サービスによる |
| Discord | 結果の返信 | 各サービスによる |

送信先での情報の扱いは、各サービスの規約に従います（[AWS プライバシー通知](https://aws.amazon.com/privacy/)、[Discord プライバシーポリシー](https://discord.com/privacy)）。

## 保存と削除

- この bot はデータベースを持たず、結果を返信した後に入力や結果を保存しません。
- 音声、文字起こし、録音の状態は、処理のあいだだけ非公開の保管場所（Amazon S3）に置きます。要約を投稿したとき、または処理に失敗したときに削除します。削除できずに残ったものも、作成から 1 日で自動的に消えます。
- 処理の記録（ログ）は 30 日間保存し、その後自動的に消えます。通常はコマンド名と処理時間だけを記録します。処理に失敗したときは、原因を調べるために入力と結果を記録することがあります。ただし、/summarize-voice の録音リンクと /summarize の要約結果は記録しません。
- 要約や文字起こしの本文はログに記録しません。
- Discord に投稿された結果は Discord 上に残ります。消したいときは Discord で削除してください。

## 録音について

- `/record-start` で録音を始めると、実行したチャンネルに開始を知らせる投稿をします。録音中は bot の表示名の先頭に「[録音中]」が付きます。
- 録音されたくない人は、録音中に `/record-optout` を実行してください。その回の録音から、その人の音声をすべて（実行前の分も含めて）除きます。録音が終わった後の実行や、次の録音には効きません。
- 録音中の音声は、録音を処理するサーバーの一時領域に置き、処理が終わると削除します。
